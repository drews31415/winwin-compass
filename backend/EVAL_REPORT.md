## 개선 필요 항목

- **Q01** `서울에서 카페 매출이 가장 높은 상권 3개 알려줘`: expected `data_query`, actual `data_query`
  - 누락 키워드: 월평균/평균/추정매출
- **Q02** `홍대 상권 폐업률이 어떻게 돼?`: expected `data_query`, actual `risk_detail`
  - 누락 키워드: %
- **Q12** `시니어 창업자가 받을 수 있는 지원사업 있어?`: expected `policy`, actual `report`
- **Q17** `강북구 저자본 카페 추천해줘`: expected `report`, actual `general`

## 평가 기준

- `intent_correct`: API가 반환한 intent와 기대 intent가 일치하는지 확인
- `keywords_found`: 답변 본문에 기대 키워드 또는 동의어 그룹이 포함되는지 확인
- `data_expectation_met`: 데이터형 질문에서 연도, 분기, 비율, 금액, 점수 등 근거 수치가 포함되는지 확인
- 최종 Pass 기준: intent 일치 + 키워드 충족 + 데이터 근거 충족
